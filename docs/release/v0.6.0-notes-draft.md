## Release body

**BurnGuard 0.6.0: the open-source Claude Design alternative that runs on the Claude Code or Codex you already pay for.**

### What's new

- **Take a project anywhere.** Export a project as a portable `.burnguard-project` bundle and restore it on another computer. The bundle carries project files, sources, checkpoints and the design system. BurnGuard's saved provider and access tokens and its local configuration are left out; review your own project files and attachments for secrets before sharing a bundle. Restores always create a new project and report missing themes or fonts.
- **Hand off to production.** The handoff export now includes a machine-readable manifest (regions, design tokens, components, routes, mocked interactions and the backend work they imply), a readable `HANDOFF.md` and a prompt for coding CLIs, plus copyable commands to continue in Claude Code or Codex. Nothing is launched from the app.
- **See why a run failed.** Settings > Runtime diagnostics lists each CLI connection with its version and capabilities, plus the stage where recent generations stopped. A failed or interrupted project can resume from the files already saved, without rerunning the turn.
- **Sharper designs by default.** Generation guidance for visual quality now covers websites, decks, graphics, logos and diagrams. The Quality panel adds four advisory checks: visible separator dashes, placeholder copy, too many eyebrow labels and repeated primary calls to action.
- **More attachments work.** GIF images are accepted, and PNG, JPEG, WebP and GIF files whose metadata embeds SVG text (such as C2PA content credentials) now decode.
- **Safer image handling.** WebP files are validated against the container rules before decoding, and colour sampling of untrusted images runs in a separate process, so a malformed image can no longer take the backend down.
- **Starts in your language.** On first run the app follows your system language: Korean, Simplified Chinese, or English for every other language. A language you pick in Settings always wins and is kept.
- **A one-time star request.** After your first successful export or publish, BurnGuard asks once whether you would star the project on GitHub. It never repeats, and nothing is sent anywhere.

### Install and update

Windows and macOS installers, portable apps and update feeds are attached. macOS packages target Apple silicon on macOS 14 or later. Keep your `.burnguard` folder; it holds your projects and settings.

Packages are currently unsigned. Cafe24 and Imweb packages require manual installation and have not been validated in a live customer shop.
