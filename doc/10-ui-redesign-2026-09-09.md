## 실제 실행에서 발견한 시작 실패

사용자 기본 프로필에는 폴더가 사라진 과거 프로젝트 행이 있었다. 한 프로젝트의 `tree_missing`가 startup 전체로 전파되어 서버가 시작되지 않았다. 해당 프로젝트의 복구만 보류하고 정상 프로젝트는 계속 초기화하도록 바꿨다. 파일 API는 `project_directory_missing`를 반환하고 UI는 폴더 복원·다시 시도·홈 이동을 안내한다.

DB 행, 미완료 작업, receipt와 사용자 파일을 삭제하지 않았다. 누락 여부는 ENOENT만 취급하며 잘못된 receipt·안전하지 않은 파일 경계의 검증은 유지한다. 사용자 프로필 조사에는 읽기 전용 DB 조회만 사용했고, 회귀는 독립 테스트 DB에서 실행했다.
