# Image style and purpose gallery

21 independently authored examples pair every BurnGuard image treatment with a purpose, covering all 13 domains. This is a selection of combinations, not the full 21 × 38 recipe matrix. Choose the corresponding **Image style** and **Image purpose** under Direction, then adapt the brief to your own project.

These fictional creative examples were generated on 2026-09-11 with Codex's built-in `image_gen` tool. They are not app screenshots, real products, factual diagrams or endorsements. No external example prompt or image was copied into this gallery. Each native PNG is preserved without conversion, resizing or retouching; these documentation assets are excluded from desktop runtime resources.

## Reproduce or adapt a brief

Each request used exactly `shared_prompt + "\n\n" + example.prompt` from the manifest, with no reference-image input. The gallery briefs below are the actual second part of each request. Keep the shared instructions when reproducing; replace the fictional subject, palette and crop deliberately for a new placement. Actual output depends on the available model and is not deterministic.

### Shared prompt

```text
Create one original finished square 1024x1024 image for a design-tool documentation gallery. This is a fictional creative example, not a real product or evidence. Fill the square with the artwork, with deliberate composition and a clear focal hierarchy. Do not include text, logos, watermarks, captions, labels, a title card or a surrounding sample-board border. Do not imitate a named artist, existing campaign or recognizable brand. Make the requested visual medium unmistakable. Output a single image.
```

### Visual review and dimensions

The native tool returned 1254 × 1254 PNGs despite the requested 1024 × 1024 size. We preserved those originals. All 21 outputs received visual review; exact file dimensions, byte counts and SHA-256 hashes are recorded in the manifest. Asset checks verify catalog coverage, PNG integrity and distinct bytes; they do not establish perfect instruction adherence or factual accuracy. The lifestyle, assembly, editorial and portrait examples have the specific deviations noted below.
