# BurnGuard v0.5.29

This maintenance release includes the reliability, security, desktop and
usability fixes merged on October 8–9, 2026.

## Protecting projects and recovery

- Checkpoint snapshots are published with integrity manifests and durable
  writes. Interrupted replacements recover the previous verified pair;
  incomplete new snapshots are rejected rather than treated as legacy data.
- Artifact publication and rollback flush their durable state before
  committing. Design-token and font CSS updates use atomic replacement.
- Deleted projects can be restored from Recently Deleted during their
  retention period.
- Database migrations back up existing databases, reject unknown newer
  schemas and check foreign-key integrity. CI now rejects migration files
  that would reorder already published migrations.
- Export publishing rechecks the validated archive digest and size limit.
  A damaged checkpoint receipt no longer prevents a project bundle export.

## Provider and watcher reliability

- Provider stdout parsing is bounded, and cancellation tests now exercise
  owned children and detached descendants on Windows as well as POSIX.
- Codex image notifications no longer depend on a filename hint containing
  the thread ID. The scanner still validates and selects the current
  thread's files, so images can arrive before a turn finishes.
- Project watchers coalesce bursts, cap the debounce wait and avoid a
  redundant inspection of an unchanged tree. Shutdown closes admission
  before draining work, including events racing startup or an active scan.
- Browser launch and cleanup handle transport settlement and resource
  lifetimes more reliably.

## Desktop and everyday use

- macOS discovers provider CLIs from login-shell and common Node-manager
  paths. Busy ports and profile conflicts have clearer native remedies.
- Native shutdown and update dialogs use localized text. Active generation
  receives a close confirmation, and comment drafts survive reopening.
- Quick Comment uses Alt/Option+C, and Ctrl+Y works in both history handlers.
- CLI probe failures have a distinct explanation and recovery guidance.
  Temporary event-stream reconnection does not unnecessarily block input.
- Oversized imports display the supported limit where available and retain
  entered form values. Korean platform presets and localized READMEs were
  corrected.
- macOS update-cache pruning is serialized with download admission.

## Security and verification

- Local bootstrap requires launcher-held authority; an Origin header alone
  cannot obtain a capability. Authenticated page reload remains supported.
- Token-bearing Figma requests refuse redirects. SVG direction previews
  receive protective raw-file headers, and archive extraction uses the
  containment resolver.
- Provider logs and completion messages avoid private staging paths.
  Third-party notices and settings-storage documentation were updated.
- Ubuntu CI invokes every discovered test file without baseline exclusions,
  including real Chromium conformance and PDF/PNG/PPTX smoke checks.
  New watcher and image regressions also run on macOS and Windows.

## Installation

Use the Windows x64 installer or portable ZIP, or the macOS arm64 installer
or portable ZIP. Extract portable packages completely before opening them.
Packages remain unsigned: Windows may require **More info → Run anyway**;
macOS may require **System Settings → Privacy & Security → Open Anyway**.
Verify downloads against the platform-specific SHA-256 files.

This release does not add crash-orphan recovery or a persisted tree-hash
cache. Those remaining proposals are not represented as completed fixes.
