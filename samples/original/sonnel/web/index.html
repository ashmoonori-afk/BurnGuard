손끝이 먼저 이해하는 소리. 하나의 다이얼로 책상 위의 리듬을 바꾸는 사운드 오브젝트의 콘셉트입니다.

01 / THE OBJECT

손안의 무게.
공간의 여백.

부드러운 삼각형은 손이 놓일 자리를 만듭니다. 낮게 기운 다이얼은 시선을 내려도, 손을 뻗어도 자연스럽게 닿습니다.

버튼을 늘리는 대신 동작을 줄였습니다. 돌리고, 멈추고, 다시 듣는 작은 행동에 집중합니다.

03 / MATERIAL INTENT

차갑지 않은 정밀함.

A

Matte shell

빛을 반사하기보다 받아들이는 무광 표면. 손에 남는 촉감을 형태의 일부로 생각합니다.

B

Orange dial

사용할 부분은 숨기지 않습니다. 선명한 색이 조작의 시작점을 알려줍니다.

C

Quiet base

책상과 닿는 면은 넓고 낮게. 움직이는 손과 머무는 물건 사이에 안정감을 둡니다.

04 / DAILY RITUAL

작은 순서가
하루를 바꿉니다.

01 — 놓고

노트 옆, 손이 닿는 거리에 놓습니다. 비워 둔 책상 한 모서리면 충분합니다.

02 — 고르고

집중의 시작에는 STILL, 생각을 펼칠 때는 DRIFT. 오늘의 속도를 고릅니다.

03 — 돌리고

공간을 채우기보다 여백을 남깁니다. 하던 일을 방해하지 않는 정도를 찾습니다.

06 / BEFORE YOU ASK

Good questions.

지금 구매할 수 있나요?

SONNEL은 BurnGuard의 가상 브랜드 샘플입니다. 판매하거나 주문을 받지 않습니다.

소리가 나오나요?

모드 설명과 레벨 표시만 바뀝니다. 음원과 연결하지 않은 인터랙션 스터디입니다.

왜 다이얼이 하나인가요?

한 번의 손동작을 선명하게 만들기 위해서입니다. 기능의 수보다 사용 순간의 명료함을 먼저 설계했습니다.
