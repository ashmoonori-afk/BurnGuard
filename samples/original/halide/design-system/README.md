# HALIDE

An invented optics studio, used here to demonstrate the bundled liquid glass ring on a real layout
rather than in isolation.

## Direction

Deep indigo ground, teal mid-field, amber horizon. The brand mark is a lens: a circular element with
a high-transparency glass ring around it. Everything in the composition exists to be looked through
— the measured grid, the horizon band, the meridian — because a refracting ring is only legible when
something structured passes behind it.

## Why the ring is not glassmorphism

The usual UI recipe is a blur, a translucent white fill and a 1px border. It has no refraction, so
it reads as frosted plastic. This system uses `liquid-glass/liquid-glass.js`, which displaces the
sampled radius across the band using the gradient of a convex-lens height field: the inner half
pushes the background outward, the outer half pulls it inward, and both converge on the ring
centreline. Straight lines bend as they cross the band and stay straight outside it.

## Assets

`assets/hero.png` (1536×1024) is generated by that same module — the grid, horizon and meridian are
drawn to a canvas, a gradient disc is placed, and the ring is composited over it. Nothing in the
image is hand-painted, so it is an honest sample of what the asset produces.

## Provenance

The brand, its copy, and everything depicted are invented. No real company, product, price or
testimonial appears. Type is bundled locally (Bebas Neue, DM Sans, IBM Plex Mono) and loaded through
`fonts/fonts.css`; there is no network dependency at runtime.
