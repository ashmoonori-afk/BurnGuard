손끝으로 신호를 탐색하는 소리 실험실. 하나의 다이얼로 질감과 반복, 간격을 고르는 사운드 합성 오브젝트의 콘셉트입니다.

01 / THE OBJECT

작은 조작.
선명한 신호.

부드러운 삼각형은 손이 놓일 자리를 만듭니다. 낮게 기운 다이얼은 시선을 내려도, 손을 뻗어도 자연스럽게 닿습니다.

버튼을 늘리는 대신 동작을 줄였습니다. 돌리고, 멈추고, 다시 듣는 작은 행동에 집중합니다.

03 / MATERIAL INTENT

차가운 표면, 정확한 접점.

A

Matte shell

차가운 회청색 무광 표면이 조작부의 경계를 드러냅니다. 손이 닿는 위치를 계기판처럼 명료하게 정리합니다.

B

Cobalt dial

사용할 부분은 숨기지 않습니다. 선명한 색이 조작의 시작점을 알려줍니다.

C

Quiet base

책상과 닿는 면은 넓고 낮게. 움직이는 손과 머무는 물건 사이에 안정감을 둡니다.

04 / DAILY RITUAL

신호를 고르고,
변화를 읽습니다.

01 — 놓고

노트 옆, 손이 닿는 거리에 놓습니다. 비워 둔 책상 한 모서리면 충분합니다.

02 — 고르고

집중의 시작에는 STILL, 생각을 펼칠 때는 DRIFT. 신호의 성격을 고릅니다.

03 — 돌리고

레벨을 움직이며 표시의 변화를 읽습니다. 작은 입력이 명료한 피드백으로 돌아오는 감각을 설계합니다.

06 / BEFORE YOU ASK

Good questions.

지금 구매할 수 있나요?

SONNEL은 BurnGuard의 가상 브랜드 샘플입니다. 판매하거나 주문을 받지 않습니다.

소리가 나오나요?

모드 설명과 레벨 표시만 바뀝니다. 음원과 연결하지 않은 인터랙션 스터디입니다.

왜 다이얼이 하나인가요?

한 번의 손동작을 선명하게 만들기 위해서입니다. 기능의 수보다 사용 순간의 명료함을 먼저 설계했습니다.
