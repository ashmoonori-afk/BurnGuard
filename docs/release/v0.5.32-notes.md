# BurnGuard v0.5.32

BurnGuard v0.5.32 replaces the color palettes of the ten classic built-in
themes with palettes made for BurnGuard, checks every built-in theme against
WCAG 2.2 AA contrast thresholds, adds two built-in themes (bringing the
catalogue to 43 themes across 33 original themes and 10 classic themes),
removes the HALIDE sample collection and third-party layout references, and
makes Codex image detection reliable in newly created conversation threads.

## Built-in themes and contrast checks

- On fresh installs, the ten classic built-in themes (**Light**, **Dark**,
  **Cupcake**, **Retro**, **Cyberpunk**, **Synthwave**, **Luxury**,
  **Dracula**, **Nord**, and **Business**) now ship with color palettes made
  for BurnGuard instead of palettes converted from an open-source UI library.
  Theme names and IDs are unchanged, and each theme keeps its visual mood
  (such as crisp neutral, cool charcoal, warm pastel, kraft paper, acid
  yellow, violet night, warm black and gold, aubergine, frost, and sober
  charcoal) while every brand and status color token across all 73 tokens per
  theme is rewritten (for example, Synthwave's primary button changes from
  pink to orange). Their website and slide preview thumbnails were
  regenerated, and the related third-party palette license notice and per-file
  attributions were removed because no third-party palette ships any more.
- Because built-in theme files are copied into your local profile only when a
  theme is first seeded, upgrading from v0.5.31 or earlier keeps any theme
  files already in your profile untouched. Fresh installs receive the new
  classic palettes, and the two new themes below are added on both fresh and
  upgraded installs.
- All 43 built-in themes are now tested against WCAG 2.2 AA contrast
  thresholds: every text color pair (including 9.5–12px captions and labels)
  reaches at least 4.5:1, and borders, focus rings, and primary controls
  reach at least 3:1 against their background. To meet these thresholds, the
  31 existing original theme palettes received small adjustments to caption
  and label text shades and border strength.
- Added two built-in themes, growing the catalogue from 41 to 43 themes (31
  to 33 original themes), with 43 website examples, 43 generated WebP
  illustrations, and 43 website thumbnails in desktop packages:
  - **Modular Configurator Theme** (`modular-configurator`): built for
    modular shelving and ergonomic furniture configurators, with front
    elevation views of each bay, finish swatch grids, and a sticky
    specification panel.
  - **Exploded Field Module Theme** (`exploded-field-module`): built for
    rugged field hardware and repairable electronics, with numbered module
    breakdowns, dense capability tables, and component upgrade tables.
- Thirty existing themes gained layout rules for detail pages and showcase
  pages, covering product detail pages for fashion, furniture, and
  electronics, creative portfolios, B2B product UI, and chaptered showcase
  pages.

## Samples and reference guidance

- Removed the **HALIDE** sample collection (website, slide deck, graphic, and
  design system) and the bundled liquid-glass refraction effect script, and
  removed liquid-glass references from generation prompts. The bundled
  original samples now comprise four collections (**SONNEL**, **FOLIOVER**,
  **ODDWARD**, and **VELUNE**), and the Examples view shows 12 sample cards
  instead of 15. On existing installs, projects and files already created or
  copied into your workspace are kept.
- Theme READMEs and skills no longer link navigation, hero, and footer
  layouts to outside gallery websites while keeping the layout rules
  themselves in BurnGuard's own words. Slide composition profiles now use
  neutral names instead of naming outside decks and brand guides, the logo
  guide no longer lists outside books or agencies as sources, and an
  illustration labelled with outside brand names was removed from the
  documentation. Required open-source notices (bundled open fonts, Lucide
  icons, the CC BY 4.0 StyleGallery-adapted taste guidance, research
  citations, and dependency notices) remain in place.

## Reliability

- When Codex creates a new conversation thread and saves generated images into
  that thread's folder, BurnGuard now watches the new thread folder directly
  from the start of the run and closes the watcher when the run ends, so
  images generated in a brand-new thread are picked up reliably without
  depending on a recursive parent-folder watcher noticing the new subfolder in
  time.

## Installation

Use the Windows x64 installer or portable ZIP, or the macOS arm64 installer
or portable ZIP. Extract portable packages completely before opening them.
Packages remain unsigned: Windows may require **More info → Run anyway**;
macOS may require **System Settings → Privacy & Security → Open Anyway**.
Verify downloads against the platform-specific SHA-256 files.
